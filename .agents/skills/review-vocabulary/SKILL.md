# Review picture-book vocabulary

Review level-scoped entries and all derived-picture-book usages. New picture-book entries and inline targets are limited to `aa` through `n`; higher retained level records do not authorize new picture-book vocabulary. Review-only means no edits; text-only fixes preserve card bytes.

Read each entry, every inline usage, exact level and locale contracts, and `references/source-policy.md`. Determine exact sense and grammatical role before research. Browse live authoritative monolingual dictionaries or standards on every run; use two independent sources for ambiguous sense, pronunciation, region, polyphony, simplification, or part of speech.

Check standard locale term, story sense, part of speech, pronunciation, learner definition, forms, writing metadata, and every claimed alignment. Use broad American English IPA where specified and standard Putonghua Hanyu Pinyin with correct tone/neutral-tone treatment. Never infer curriculum placement from familiarity, another locale, English Lexile, or Chinese character familiarity; an empty alignment is preferable to an unsupported one.

Confirm directory ID/level, locale coverage, marked surface forms, shared concept, wordless `card.webp`, and Git LFS. Visually inspect the card when visual access is available. After authorized corrections, validate every affected book.

Return findings by path and locale with field, current value, supported value, source links, and learner impact. Return `PASS` only when requested entries have adequate live evidence and no findings.
